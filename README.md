# 🍔 Food Munch - Responsive Website

A fully responsive food ordering website built using HTML, CSS, and Bootstrap. This project showcases modern UI design, responsive layouts, and reusable components.

---

## 🚀 Live Demo

(https://github.com/Dineshmara/Food-Munch-Website — GitHub Pages)

---

## 📌 Features

* ✅ Fully responsive design (Mobile, Tablet, Desktop)
* ✅ Interactive navigation bar with smooth scrolling
* ✅ Attractive banner (Hero section)
* ✅ "Why Choose Us" feature cards
* ✅ Food menu categories grid
* ✅ Healthy food promotional section
* ✅ Delivery & payment information section
* ✅ Modal popup (Gift Voucher)
* ✅ Social media integration
* ✅ Clean and modern UI

